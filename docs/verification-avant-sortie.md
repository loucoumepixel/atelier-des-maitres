# Vérification avant sortie

Dix minutes sur un vrai téléphone avant de publier une version sur le Play Store. Les tests automatiques (le « parcours » sur un téléphone virtuel) passent déjà avant chaque version ; cette liste couvre ce qu'ils ne voient pas : le son, la fluidité, le rendu, le ressenti.

Installer l'APK de la dernière Release GitHub, **par-dessus** la version précédente (sans désinstaller), pour vérifier que la progression est gardée.

## 1. Démarrage (1 min)
- [ ] L'intro du studio se joue, puis l'accueil s'affiche.
- [ ] Le rang, la série de jours et la progression d'avant la mise à jour sont toujours là.

## 2. Galerie (1 min)
- [ ] Les toiles s'affichent, les pourcentages sont justes, les toiles verrouillées sont emballées.
- [ ] L'exposition du mois et la toile du jour sont visibles.

## 3. Atelier (4 min)
- [ ] Ouvrir **une toile déjà commencée** : elle reprend là où elle était, sans zone rouge inattendue.
- [ ] Ouvrir **une toile neuve** : le découpage se fait, la musique de son époque démarre.
- [ ] Peindre une dizaine de zones : la couleur s'étale, la note de bois sonne, le téléphone vibre.
- [ ] Le bouton loupe trouve une zone ; le petit œil montre l'original.
- [ ] Annuler, rétablir, gomme.
- [ ] Changer la matière (Plate, Légère, Épaisse) : le relief change.
- [ ] Couper le son, puis la musique : tout se tait. Les rallumer.
- [ ] Tourner le téléphone en paysage, puis revenir : rien ne se perd.
- [ ] Quitter l'application (bouton accueil), la rouvrir : la toile est sauvegardée.

## 4. Fin de toile et musée (3 min)
- [ ] Terminer une toile en Facile (une petite) : l'écran Bravo, la fanfare, l'avant / après à faire glisser.
- [ ] Le guide raconte la toile (voix de Nathalie en français).
- [ ] Le musée s'ouvre et reste fluide ; toucher un tableau ouvre la vue face à face, le zoom marche, changer de cadre marche.

## 5. Langue et partage (1 min)
- [ ] Partager une toile : l'image part bien dans une messagerie.
- [ ] Passer le téléphone en anglais (ou Paramètres › Applications › Atelier des Maîtres › Langue) : les textes sont traduits, rien ne déborde.

Si une case ne passe pas : ne pas publier, et écrire dans le projet ce qui s'est passé (une capture d'écran aide beaucoup).
